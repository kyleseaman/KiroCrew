# Coder AWS workspace template

Use this template when you already have a Coder control plane and the AWS
network/IAM resources required by the variables in `main.tf`. It creates one
ARM Amazon Linux 2023 EC2 workspace with an encrypted persistent gp3 root disk.

The default `c8g.large` is the lowest-cost starting point in this template.
`c8g.xlarge` adds CPU and memory; `m8g.large` keeps two vCPUs and adds memory.
Stopping the Coder workspace stops EC2 compute billing, but its root disk remains
persistent and billable.

The agent starts in `/home/coder/workspace`. The template creates that directory
as `coder:coder` with mode `0700`, so it remains private while retaining the
execute bit required to enter a directory. It also enables systemd user
lingering and verifies a transient user scope during bootstrap. That scope is
the conservative boundary used to keep ordinary build descendants visible to
the gateway after an ACP runtime disconnects.

```bash
coder templates push kirocrew-arm --yes \
  --directory deploy/coder-aws/workspace \
  --var region=us-east-2 \
  --var subnet_id=subnet-... \
  --var security_group_id=sg-... \
  --var instance_profile_name=... \
  --var tailscale_auth_parameter=/kirocrew/poc/tailscale-auth-key \
  --var kiro_api_key_parameter=/kirocrew/poc/kiro-api-key

coder create crew-dogfood --template kirocrew-arm \
  --parameter instance_type=c8g.large \
  --parameter volume_gb=30 --yes
```

`crew-dogfood` is an optional bootstrap/smoke workspace. Managed Kiro Crew
sessions use opaque `crew-*` names created from this template; the gateway does
not adopt, stop, or delete the bootstrap workspace.

The template expects an outbound-only public subnet to avoid a NAT Gateway's
fixed hourly charge, an instance profile scoped to the two named SSM parameters,
and a reusable tagged Tailscale auth key. It does not place the Coder automation
token in the workspace. Configure that gateway-only bearer in **Settings →
Coder** after the workspace is reachable.

For the variables generated by the companion stack, setup order, verification,
and teardown, see the [remote-host guide](../../../docs/guides/remote-and-mobile.md#aws--coder-graviton-dogfood-poc).
